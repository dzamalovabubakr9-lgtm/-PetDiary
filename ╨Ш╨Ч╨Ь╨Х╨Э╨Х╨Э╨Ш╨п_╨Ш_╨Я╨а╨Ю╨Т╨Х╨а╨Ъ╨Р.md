# Исправленная сборка PetDiary

Эта сборка подготовлена на основе исходного проекта и предыдущей ревизии.

## Что включено

- Django-проект PetDiary с приложениями accounts, pets, diary, care, advice, api и assistant.
- Настройки PostgreSQL через `DATABASE_URL` и драйвер psycopg 3.
- Регистрация, вход, выход, профиль и смена пароля.
- Штатный механизм Django для восстановления пароля по электронной почте.
- JWT-эндпоинты REST API и проверка принадлежности данных текущему пользователю.
- ИИ-помощник с историей диалогов.
- Пример переменных окружения `.env.example` без реальных секретов.
- `.gitignore` и аудит покрытия учебных тем.

## Важные ограничения

1. В архиве методических материалов отсутствует отдельное задание по теме 5, поэтому соответствие теме 5 не подтверждено.
2. Для восстановления пароля используется штатный механизм Django. Отдельная таблица с SHA-256-хешами одноразовых токенов в этой сборке не реализована.
3. Нельзя подтвердить работу SMTP, PostgreSQL и внешнего ИИ-провайдера без настроенных учетных данных и доступных сервисов.
4. Для production необходимо задать собственный `SECRET_KEY`, `DATABASE_URL`, `ALLOWED_HOSTS`, HTTPS и параметры почты/ИИ в `.env`.
5. Git-репозиторий и удаленный origin нельзя создать за пользователя: после распаковки нужно выполнить `git init`, `git add`, `git commit` и настроить remote.

## Проверка, выполненная при упаковке

- Все Python-файлы успешно прошли `python -m compileall`.
- Django `manage.py check`, миграции и тесты не запускались: Django и PostgreSQL в среде упаковки не установлены/не настроены.

## Запуск локально

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # Windows PowerShell: Copy-Item .env.example .env
```

Отредактируйте `.env`, затем выполните:

```bash
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py migrate
python manage.py test
python manage.py runserver
```

Для полноценной проверки используйте PostgreSQL и тестовые SMTP/ИИ-ключи. Не публикуйте `.env`.
