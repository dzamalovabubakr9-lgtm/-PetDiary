@H2 Раздел 2. Анализ предметной области
@P Проведён анализ: роли (владелец, админ), объекты (питомцы, дневник, процедуры, советы, профиль), действия (создание, просмотр, редактирование, удаление).
@H2 Раздел 3. Проектирование макетов
@P Подготовлены макеты страниц:
@LIST:
- Главная (целевая страница с карточками).
- Регистрация, вход, выход.
- Профиль пользователя (просмотр + редактирование).
- Список питомцев, карточка питомца (с измерениями).
- Добавление и редактирование питомца.
- Дневник питомца (список, записи, создание, редактирование, удаление).
- Процедуры (список, создание, редактирование, удаление, статус выполнения).
- Советы по уходу (список, просмотр).
@H2 Раздел 4. Реализация HTML/CSS/JavaScript
@P Технологии: HTML5, CSS3, JavaScript. Визуальный стиль: светлый фон (#f7f9fc), зелёный акцент (#2e6f47), шрифты Segoe UI/Roboto, карточки с тенями, скруглённые углы, кнопки с hover-эффектами.
@H2 Раздел 5. Основные страницы
@P Реализованы страницы (Django + шаблоны):
@LIST:
- base.html — базовый шаблон с навигацией, подвалом, сообщениями.
- pages/home.html — главная страница.
- accounts/login.html, register.html, logout.html, profile_detail.html, profile_edit.html, change_password.html — аутентификация.
- pets/pets_list.html, pet_detail.html, pet_form.html, pet_confirm_delete.html — питомцы.
- diary/diary_list.html, diary_detail.html, diary_form.html, diary_confirm_delete.html — дневник.
- care/procedures.html, procedure_detail.html, procedure_form.html, procedure_confirm_delete.html — процедуры.
- advice/advice_list.html, advice_detail.html — советы.
@H2 Раздел 6. Адаптивность
@P Реализована адаптивность через viewport + медиа-запросы; сетки через CSS Grid; таблицы откликаются на ширину экрана.
