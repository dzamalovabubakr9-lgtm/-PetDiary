@H2 Раздел 1. Введение
@P Цель практики — выполнение задания «Проектирование информационной системы» по теме «Проектирование информационных систем».
@P Разрабатываемая система — PetDiary: веб-приложение для владельцев домашних животных.
@P Предметная область: сущности «Питомец», «Дневник питомца», «Владелец», «Ветеринарная история»; процессы «Ведение дневника», «Планирование процедур», «Получение советов по уходу».
@H2 Раздел 2. Анализ предметной области
@P Проведён анализ предметной области: идентифицированы основные сущности и их атрибуты, определены взаимосвязи, поведение пользователей и бизнес-процессы системы.
@H2 Раздел 3. Определение требований и заданий преподавателя
@P В соответствии с формулировками заданий преподавателя и методичкой:
@LIST:
- Проектирование информационной системы (UML-диаграммы: Use Case, Class, Sequence, Activity, ERD).
- Выбор и обоснование стека технологий.
- Проектирование и разработка базы данных.
- Регистрация, аутентификация, авторизация.

- Разграничение прав доступа.
- Разработка веб-интерфейса.
- Разработка REST API.

@P Проведён обзор и выбор стека:
@TABLE:
| Компонент | Выбрано |
| --- | --- |
| Программная среда | Python (3.14) |
| Веб-фреймворк | Django |
| База данных | PostgreSQL |
